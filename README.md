# Gift and Bliss Supplies: Text-to-SQL App

Starter code for the **AI Guided: Gift and Bliss Supplies** project by **Instrovate Technologies** ([cvfine.com](https://cvfine.com)).

You build a dashboard, an AI that turns plain English into SQL, a backend API and a web app on a real retail dataset. This repository is only the starting point; the dataset is loaded for you with your personal token after you enrol.

## Start here (no installs needed)

1. Click the green **Use this template** button, then **Create a new repository**. Name it, choose **Public**, and create it. This is your own copy.
2. On your new repository click **Code**, then **Codespaces**, then **Create codespace on main**. A full VS Code opens in your browser. Wait about two minutes for it to finish setting up.
3. In the terminal at the bottom run: `bash load_data.sh` and paste your personal token when asked. You should see 5000 orders.
4. Follow the step-by-step instructions for each milestone on your cvfine.com project page.

Your work is saved in your own repository. Link it when you submit a milestone, and share it with the world.
